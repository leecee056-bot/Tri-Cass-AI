# Templates library

## Pack

Primary pack: [`stephen-taipei/awesome-tailwind-ui-templates-1000`](https://github.com/stephen-taipei/awesome-tailwind-ui-templates-1000) (MIT).

Optional extras (best-effort):

- `learning-zone/website-templates`
- `dawidolko/Website-Templates`

One-click **Download template library** in the Templates sidebar page extracts into Electron `userData/template-packs/` and builds `index.json`. Target: **≥1000** usable HTML entries (verified **1043** from the primary pack alone).

## Use

1. Browse / search / filter by category or tag.
2. **Use** copies the template into the workspace as a project (`index.html` + sibling assets).
3. **AI edit** selects the template for chat — ask in plain English; you don’t need a code editor.
4. Gallery is windowed/virtualised by paging (48 at a time) for performance.
